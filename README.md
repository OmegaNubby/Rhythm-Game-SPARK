# Rhythm-Game-SPARK
ECE 302 Spark Challenge / Final Project.
____________________________________________________

Our project is going to be a rhythm game whose main mechanic is pressing four physical tiles that are each pressure-sensitive. Notes will fall down four lanes on TFT displays, and the player will press the matching tiles when a note reaches the “hit line” at the bottom. The game will incorporate both short “staccato” notes and longer “legato” hold notes. The songs will be loaded in from an SD card, and the seven-segment display will show the player’s live score. The LCD will handle song selection, difficulty, and game status.
